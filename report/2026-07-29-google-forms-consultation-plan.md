# 1:1 상담 신청 — Google Forms 연동 작업 순서 보고서

- 작성일: 2026-07-29
- 관련 파일: `./index.html` (CTA 버튼: "1:1 상담 신청하기")

## 1. 배경 및 결정 사항

랜딩 페이지의 "1:1 상담 신청" 기능은 별도 백엔드 없이 **Google Forms**로 처리하기로
결정했습니다. 응답은 Google Sheets에 자동 저장되고, 이메일 알림도 무료로 설정할 수
있어 현재 단계에는 가장 적은 비용으로 빠르게 운영할 수 있는 방식입니다.

## 2. 전체 작업 순서

### Step 1. Google Forms 신청서 생성 (사용자 작업 필요)
- Google 계정(예: triwon20@gmail.com)으로 [forms.google.com](https://forms.google.com)에서
  새 양식 생성
- 수집 항목(안):
  - 이름
  - 연락처(전화번호)
  - 이메일
  - 소속 대학교 / 학년
  - 희망 상담 방식(전화/화상/방문 등, 선택형)
  - 희망 상담 일시(단답 또는 날짜/시간 선택형)
  - 문의 내용(장문형)
  - 개인정보 수집·이용 동의 (체크박스, 필수)
- 양식 설명란에 "Recode Coding 1:1 상담 신청" 등 안내 문구 작성

### Step 2. 응답 수집 설정 (사용자 작업 필요)
- 양식의 "응답" 탭에서 Google Sheets 연결(응답 자동 저장)
- "응답" 설정에서 새 응답 발생 시 이메일 알림 받기 옵션 활성화
- 필요 시 응답자에게 자동 확인 메일 발송 옵션 검토(Google Forms 애드온 필요할 수 있음)

### Step 3. 공유 링크 확보 (사용자 작업 필요)
- 양식 우측 상단 "보내기" → 링크 아이콘에서 공유 URL 복사
  (예: `https://forms.gle/xxxxxxxx`)
- 필요 시 "URL 단축"을 활성화해 짧은 링크 사용

### Step 4. 연동 방식 결정
새 탭 링크와 페이지 내 임베드(iframe) 중 하나를 선택해야 합니다.

| 방식 | 장점 | 단점 |
| --- | --- | --- |
| **새 탭 링크** (권장) | 구현 간단, Google Forms 기본 UI 그대로 사용, 다크 테마와 색 충돌 없음 | 사용자가 페이지를 이탈하는 느낌 |
| **페이지 내 임베드** | 이탈감 없이 한 페이지에서 완결 | Google Forms 기본 배경이 흰색이라 현재 다크 테마와 시각적으로 부조화, 커스텀 CSS 적용 불가 |

→ 별도 요청이 없다면 **새 탭 링크 방식**으로 진행 권장

### Step 5. `index.html` CTA 버튼 연결 (Claude 작업)
- Header의 "1:1 상담 신청" 버튼과 CTA 섹션의 "1:1 상담 신청하기" 버튼의
  `href="#"`를 Step 3에서 발급받은 Google Forms 링크로 교체
- 새 탭에서 열리도록 `target="_blank" rel="noopener noreferrer"` 속성 추가

### Step 6. 동작 검증 (Claude 작업)
- 로컬 서버 구동 후 브라우저로 버튼 클릭 → Google Forms 페이지가 새 탭에서 정상
  열리는지 확인
- 테스트 응답 1건 제출 → Google Sheets 및 이메일 알림에 정상 반영되는지 확인
  (이메일/응답 확인은 사용자 Google 계정에서 직접 확인 필요)

### Step 7. 배포 후 재확인
- 실제 배포 환경(도메인 연결 시)에서도 링크가 정상 작동하는지 재확인
- 개인정보 수집 동의 문구가 관련 법령(개인정보보호법 등) 요건을 충족하는지
  최종 검토 (필요 시 전문가 확인 권장)

### 발견 사항
- 현재 CTA 버튼에 `target="_blank"`가 적용되어 있지 않아, 클릭 시 **현재 탭에서 랜딩
  페이지를 벗어나 Google Forms로 이동**합니다. 애초 계획(Step 4/5)은 새 탭 오픈을
  권장했습니다. 필요하시면 `target="_blank" rel="noopener noreferrer"` 속성을
  추가해 드리겠습니다.
- Header/Hero의 "1:1 상담 신청" 버튼은 `#cta`로 스크롤 이동만 하며, 실제 Google Forms
  링크는 최하단 CTA 섹션 버튼에만 연결되어 있습니다(의도된 설계).

### 결론
Google Forms 연동은 **정상 동작**합니다 (링크 접속·제출·응답 기록 모두 확인). 다만
새 탭 오픈 여부는 사용자 확인 후 반영 여부를 결정하는 것을 권장합니다.
