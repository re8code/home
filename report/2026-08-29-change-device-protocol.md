## 2. 발견한 문제 2건

**① `docs/CHANGE_DEVICE.md`가 빈 파일이었다.** 0바이트, git untracked. 규칙은 들어갔는데 따라야 할 내용이 없어, 다른 장비에서 세션을 열어도 이 규칙이 아무 동작도 지시하지 못하는 상태였다. 그대로 커밋했다면 빈 파일이 올라갔다.

**② 문서 개수 표기가 5개/4개인 채 남아 있었다.** 문서 세트가 6개가 되었는데 `CLAUDE.md` 본문 6곳이 옛 숫자였다 — 제1원칙 도입부("아래 **5개** 문서"인데 정작 목록에는 6개가 나열됨), "작업 시작 전 **5개** 문서를 훑어본다", 장비 간 연속성의 "위 **5개** 문서", 저장소 관례의 "`docs/` — **4개** 주요 문서", 작업 완료 후 점검 규칙의 5개 열거와 "**5개** 중 바꿀 내용이 없으면". 전부 6개(`docs/`는 5개)로 정정하고, 문서별 갱신 기준에 `CHANGE_DEVICE.md`(장비를 실제로 옮겨보며 빠진 단계·새 함정을 발견했을 때만 갱신)와 ARCHITECTURE의 ADR 한 줄을 덧붙였다.

## 3. `docs/CHANGE_DEVICE.md` 구성

2026-08-26 경로 이동(`~/dev/recode-ai/` → `~/recode-ai/`)을 실제로 수행하며 얻은 것만 담았다 — 추측으로 채운 절차는 없다.

| 절 | 내용 |
| --- | --- |
| §0 핵심 | **깨지는 것은 저장소가 아니라 도구가 절대경로를 키로 들고 있는 상태**라는 것이 이 문서 전체의 전제 |
| §1 이동 전 | 커밋·푸시 완료, 진행 내용이 저장소 문서에 있는지(메모리에만 있으면 사라진 것과 같다), 형제 저장소를 함께 옮길지 |
| §2 이동 후 — 저장소 | git 상태, 절대경로 하드코딩 0건, **모든 브랜치 pull**, 로컬 서버 응답 |
| §3 이동 후 — 경로 키 | 경로를 키로 보관되는 위치 **6종 표**(무엇이 들어 있고 잃으면 무엇이 깨지는지) + 경로키 규칙(`/`→`-`) + 이관/폐기 선택 |
| §4 자동화 | 이관 스크립트 전문 (저장소 **밖**에 두는 이유 포함) |
| §5 형제 저장소 | 한쪽만 옮기면 `../business` 상대 참조가 **경고 없이** 깨진다 |
| §6 함정 | 실제로 당한 6가지 (아래) |
| §7 마무리 | 문서 정합성 확인 필수 — 점검 항목은 `report/2026-08-29-docs-consistency-check.md`를 템플릿으로 |

### §6에 남긴 함정 6가지

1. Claude Code는 `~/.claude.json`을 메모리에 들고 있다가 **종료 시 되쓴다** — 실행 중 편집은 조용히 사라진다. 스크립트가 `pgrep`으로 중단하는 이유이자, 세션 종료 후 한 번 더 돌려야 하는 이유.
2. `history.jsonl`은 실행 중에도 append되므로 `os.replace`(inode 교체)가 아니라 **제자리 재작성**으로 처리해야 한다.
3. **`display` 필드는 건드리지 않는다** — 사용자가 타이핑한 프롬프트 원문이라 바꾸면 과거 발화를 위조하게 된다. 치환 대상은 `"project":"..."` 뿐.
4. **`"project":"..."`에는 콜론 뒤 공백이 없다** — 샘플을 `json.dumps`로 다시 찍어보면 공백이 붙어 보여 착각하기 쉽다(이번 작업에서 실제로 한 번 헛짚었다). 원문을 직접 확인할 것.
5. 세션 트랜스크립트를 지워도 **`file-history/<세션ID>/`는 함께 지워지지 않는다** — 19MB·561파일이 고아로 남아 있었다.
6. 저장소가 사라진 프로젝트 항목은 이관이 아니라 삭제 대상이되, 다른 장비에 있을 수 있으니 확인 후 지운다.

## 4. 스크립트 검증

문서에 코드를 싣기만 하고 돌려보지 않으면 프로토콜이 무용지물이므로, 문서에서 코드블록을 추출해 실제로 실행했다.

- **기능** — 가짜 `HOME`에 옛 경로 상태(프로젝트 디렉터리 + 세션 파일, `projects`/`githubRepoPaths` 항목, history 2줄, 고아 `file-history`·`session-env`)를 만들어 실행:
