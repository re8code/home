## 1. 무엇을
`recode.ai.kr`(이 저장소)의 역할을 **학습 콘텐츠 허브 → 학생·기업을 잇는 대문 1장**으로 바꾸기로 결정했다. 학습 콘텐츠 24장·about 레이어·OJ/Class/VOD 링크는 `student.recode.ai.kr`(가칭, 별도 프로젝트)로 나간다. 오늘은 **결정과 기록만** — `index.html`을 비롯한 코드는 손대지 않았다.

## 2. 왜 — 논의의 흐름
1. "전체 재편" → "recode.ai.kr은 랜딩만, 대부분이 학생 학습 내용" → **`학생 페이지 ─ 랜딩 ─ 기업 페이지`** 구조.
2. 학생 페이지는 의대(예과-본과-인턴-레지던트)처럼 단계별 성장 시스템 → 등급 확정: **학생 → 훈련생 → 랜서 → 에이전트**. 훈련생까지 수업료(훈련생=인턴), 랜서부터 실전·수익배분·별도 계약, 에이전트 = 진정한 디지털 노마드. 회원·등급·정산이 있어 정적 사이트로는 안 되므로 **별도 프로젝트**.
3. 랜딩은 대문이라 **강력한 흡입력**이 필요 — 양쪽 pain point를 건드린다. 학생: 성장→실전 투입, 우리가 정한 관문을 통과해야 하고 우리가 승인해야 랜서(학생·훈련생 전 과정을 지켜본 오랜 관찰이 평가 자산). 기업: 대졸초임 연봉으로 주니어 뽑는 셈이지만 실은 **훌륭한 개발팀을 구독** → 품질·고용 리스크 해방.
4. 우리 회사의 역할 = **검증받은 학생 + 회사 내부 베테랑 + AI Agent → 기업 니즈의 품질을 보증** → **유일한 길목**. 수많은 일당백 에이전트가 수많은 회사의 일원이 된다.
5. Claude 평가(요약): AI 시대라서 성립하는 아이템 — AI가 없앤 건 코딩이 아니라 주니어의 사다리이고, AI가 만든 가장 큰 공백은 **책임**이며, 관찰 기록은 포트폴리오가 무력화된 뒤에도 남는 신호. 급소는 "베테랑+AI만으로 충분해지면 학생은 비용이 된다"는 것 — 답은 **확장**(베테랑은 못 늘리고 학생은 늘린다)과 **관계**(한 회사를 계속 아는 사람). 파는 것은 개발이 아니라 **책임과 검증**.
6. 사용자 정정: 교습소로 이미 학생·랜서급이 여럿 있다(초기 공백 리스크 해당 없음). **핵심은 학생** — 수많은 학생이 AI 시대에 세상으로 나오는 더 안전한 관문. → 랜딩은 대칭이 아니라 **학생 쪽 비대칭**.
7. 기업은 이 공동체의 **선한 의도에 함께 하자**는 의도도 있다 → `business.recode.ai.kr` 문서 확인.

## 3. `business` 문서와의 대조
`../business/docs/Philosophy.md`와 ADR **D30**(2026-09-11)에 오늘 내용의 대부분이 이미 있었다 — 에이전시 정체성(선수-에이전트, 어미새), 사이에 서기(한 프로젝트가 두 상품), 길(입학→교육→관문→풀→실전→독립), 기업 약속(주니어 비용으로 시니어 결과), 지켜야 할 선 넷. "선한 의도에 함께"는 §6 첫 미결 항목("읍소 vs 에이전트")의 답 — **읍소도 제안도 아닌 동참 초대**. D30의 역할 분담("말을 거는 것은 `home`, `business`는 증거")과 정확히 맞다.

**갈라지는 것 셋** — 오늘 결론이 D30을 개정한다:

| | D30 (9/11) | D6 (9/13) |
|---|---|---|
| `home` | 학교 + GNB `business`가 선택 페이지 | **대문** — 학교 기능 전부 이관 |
| 학생 축 | `home`(학교) + `lancer`(관문→독립) 두 사이트 | **`student` 하나** |
| 용어 | "agent는 우리다, 사람은 lancer" | 조직=**에이전시**, 최상위 등급=**에이전트** |

근거: 학교와 관문·풀이 다른 사이트에 있으면 D30 자신이 진단한 "브릿지가 안 보이는 구조"가 학생에게 남는다 — 사다리는 한 화면에 있어야 한다. 그리고 `home`이 학교면 대문이 될 수 없다.

## 4. 용어 결정
"에이전트"가 세 뜻(우리 · 최상위 등급 · AI Agent)으로 겹치는 문제. 스포츠(**에이전시**↔선수)와 007(**에이전시**=MI6↔에이전트) 두 은유가 조직 쪽 이름이 같다는 점에서 — **조직 = 에이전시, 사람 = 에이전트, AI = 영문 "AI Agent" 고정**(겹칠 때 "AI 스태프", `Philosophy` §0 3번 "AI-Agent 스텝"이 근거). "우리는 에이전트다"의 뜻은 그대로, 명사형만 정정. 본부(초반, 유닛 양성·파견)와 대행사(후반, 플레이어 대행)가 한 단어에 담기고 §6 "에이전트의 최종 형태"가 에이전시의 본업이 된다. 랜서→에이전트 승급 = **면허**(007의 라이선스 — 단독 투입 자격). 대안으로 본부/HQ(대행 역할 못 담음, 딱딱함)·소속사(연습생→데뷔→스타, 직관적이나 B2B에 부적합)를 검토하고 기각.
