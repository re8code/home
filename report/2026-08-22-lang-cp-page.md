# lang-cp.html (C/C++ 코스 상세 페이지) 제작 보고서

- 작성일: 2026-08-22
- 작업 대상: 신규 `lang-cp.html`, `mockup.html`(C/C++ 카드 연결)

## 1. 배경

`mockup.html`의 Language(01) 섹션 5개 카드는 지금까지 클릭해도 아무 곳으로도 이동하지 않았다.
이번 작업은 그중 C/C++ 카드가 실제로 이동할 상세 페이지(`lang-cp.html`)를 처음으로 만들고 연결하는 것.
나머지 언어(Java/Python/JavaScript/Dart)는 `lang-jv.html` 등으로 동일 패턴을 따라 이후 순차 제작 예정.

## 2. 벤치마크 대상 확인

`https://korea-pass.kr/notice/noticeList.do`(모두의카드 공지사항 목록)를 클로드 인 크롬으로 직접 접속해 확인.

- 브레드크럼(홈 아이콘 > 공지사항) + 큰 타이틀 + 구분선
- 검색창(돋보기 아이콘 + placeholder)
- 분류 탭(전체/공지사항/이벤트/시스템점검, 활성 탭은 네이비 채움)
- 전체 건수 텍스트
- 카드 리스트: 흰 배경 rounded 카드 하나당 [뱃지(카테고리별 색상) + 날짜] 상단 행 + 굵은 제목 한 줄
- 하단 "더보기" 버튼(전체 너비, 테두리만 있는 버튼) → 클릭 시 다음 페이지 항목 추가 로드

## 3. lang-cp.html 구현

- 헤더/푸터/Tailwind config/Pretendard 폰트/브랜드 컬러는 `mockup.html`을 그대로 재사용해 톤을 맞춤. `[MOCKUP]` 배너는 제거(실제 페이지이므로), 헤더 sticky 오프셋도 `top-0`으로 단순화.
- 상단: 브레드크럼(홈 › 훈련 코스 › C/C++) + C++ 로고(`assets/image/cpp.png`) + 타이틀 + 소개 문구 + 구분선 — 벤치마크의 타이틀 영역 구조를 그대로 차용하되 언어 로고를 추가.
- 중단: "커리큘럼 목록" 섹션에 벤치마크 레이아웃을 적용 — 검색창(제목 부분일치 필터), 분류 탭(전체/기초/실습/프로젝트, 뱃지 색상은 브랜드그린/스카이/바이올렛으로 구분), 전체 건수, 카드 리스트(뱃지+주차+제목), "더보기" 버튼.
- C/C++ 커리큘럼 12주차 분량 신규 작성: OT/자료형 → 포인터/배열/함수 → 동적 메모리/구조체/파일 입출력/클래스/STL → 스마트 포인터/미니 프로젝트. 기초 5개·실습 5개·프로젝트 2개로 구성.
- JS 동작(프레임워크 없이 vanilla): 기본 6개 카드만 노출 후 "더보기" 클릭 시 전체 노출 + 버튼 숨김. 분류 탭 클릭 시 해당 카테고리 전체를 즉시 노출(더보기 숨김). 검색어 입력 시 제목 부분일치로 필터링, 검색 중엔 더보기 숨김 및 일치 0건일 때 안내 문구 노출.
- 하단 CTA(1:1 상담 신청) + 푸터는 `mockup.html`/`index.html`과 동일한 링크 구조 재사용(단, 훈련 코스 링크는 `mockup.html#lang` 등 앵커로 정리).

## 4. mockup.html 연결

C/C++ 카드의 `<div class="course-card ...">`를 `<a href="lang-cp.html" class="course-card ...">`로 교체. 클래스는 그대로 유지되어 hover 트랜지션 등 기존 스타일이 앵커 태그에도 동일하게 적용됨. 나머지 4개 언어 카드는 아직 대상 페이지가 없어 `<div>`로 유지.

## 5. 검증 (클로드 인 크롬, `localhost:8765`)

- `mockup.html` → Language 섹션 → C/C++ 카드 클릭 → `lang-cp.html`로 정상 이동 확인.
- 분류 탭(전체/기초/실습/프로젝트) 클릭 시 카드 필터링·건수 갱신 정상 동작(예: "프로젝트" 탭 클릭 → 2건만 노출).
- 검색창에 "포인터" 입력 → 제목에 "포인터"가 포함된 3건만 노출, 건수 텍스트 갱신 확인.
- "더보기" 버튼 클릭 → 숨겨져 있던 7~12주차 카드 노출, 버튼 자체는 사라짐 확인.
- 콘솔 에러 없음(`read_console_messages` onlyErrors 확인).

## 6. 후속 작업

- Java/Python/JavaScript/Dart용 `lang-jv.html` 등을 `lang-cp.html`을 템플릿으로 동일 패턴으로 제작하고, `mockup.html`의 해당 카드도 순서대로 연결.
- `mockup.html`이 아직 "MOCKUP" 배지가 붙은 검토용 페이지인 반면 `lang-cp.html`은 실제 페이지로 만들어졌다는 점 — 추후 `mockup.html` 자체가 실 서비스 페이지로 전환될 때 두 페이지 간 헤더/톤 정합성을 다시 한번 확인할 것.
