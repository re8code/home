### 참고 페이지 구조 요약 (liveklass.com/service/consulting)
GNB → 상단 배너(사진+헤드카피+CTA) → 서비스 소개 문구 → 고객사 성공 사례 카드 → 고객 후기 카드 그리드 → 컨설턴트(팀원) 프로필 카드 4장(사진+이름+직함+소개+태그) → 강조 CTA 배너 → Footer(회사명·대표자·사업자등록번호·주소·연락처 등 법적 고지).
→ Recode Coding의 "회사 소개"에 대입하면: 상단 배너(브랜드 메시지) → 회사/철학 소개 → (선택) 교육 성과·사례 → 원장님/강사진 프로필 카드 → 상담 CTA → Footer 회사 정보, 형태로 재구성 가능.

### 상단 배너 이미지 권장 크기
- 참고 페이지 배너: 실제 표시 영역 약 1300×630px(비율 약 2.06:1), 소스 이미지는 2048×1142px로 준비해 `object-fit: cover`로 크롭 표시(레티나 대응).
- 이 사이트(`index.html`)의 컨테이너 규격(`max-w-[1440px]`, `px-6 lg:px-10`)에 맞추면 데스크톱 기준 배너 표시 폭은 약 1360~1400px.
- 권장: **표시 영역 1400×600px(약 2.33:1, 기존 랜딩 히어로 배너와 동일 비율)** 기준으로, 레티나 대응을 위해 **소스 이미지는 2x인 2800×1200px**로 제작 후 `object-fit: cover`로 반응형 크롭. 모바일에서는 같은 이미지를 정사각형에 가깝게 크롭하므로 가로세로 중앙 피사체 배치를 권장.
