# Recode Coding 랜딩 페이지 제작 결과 보고

- 작성일: 2026-07-29
- 산출물: `./output/index.html`

## 1. 작업 개요

`task.md`의 지시에 따라 "Recode Coding"의 교육 철학을 담은 랜딩 페이지(`index.html`) 1종을
`./output` 폴더에 제작했습니다. CSS는 Tailwind CSS(CDN 방식)를 최대한 활용하여
별도 빌드 과정 없이 파일 하나로 바로 열람/배포 가능하도록 구성했습니다.

## 2. 반영한 핵심 메시지 (CLAUDE.md 기반)

프로젝트 CLAUDE.md에 정의된 "Recode Coding"의 정체성을 아래와 같이 섹션별로 구조화했습니다.

| 섹션 | 반영한 철학 |
| --- | --- |
| Hero | 지식 전달이 아닌 "훈련"이 최종 지향점 / 1:1 맞춤 컨설팅 |
| 문제의식 (학원 vs 연구소) | 1:多 지식 전달형 학원과의 차별점 |
| 핵심 철학 3원칙 | 데이터 흐름 중심 사고, 구조와 알고리즘, Agent Coding 지향(언어에 대한 깊은 이해 전제) |
| 훈련 프로세스 | 1:1 상담 → 맞춤 커리큘럼 → 지식 기반 훈련 → 신입 시니어 |
| 대상 | 대학생 대상 프로그래밍 종합 컨설팅 |
| CTA | 1:1 상담 신청 유도 |

## 3. 기술 구성

- **마크업/스타일**: 단일 HTML 파일, Tailwind CSS CDN(`cdn.tailwindcss.com`) + 커스텀 컬러(`brand`, 그린 계열)·폰트(Pretendard) 설정을 인라인 `tailwind.config`로 확장
- **폰트**: Pretendard Variable(한글 가독성), JetBrains Mono(라벨/숫자 강조)
- **반응형**: `sm/md/lg` 브레이크포인트로 그리드·플렉스 레이아웃 대응 (모바일 1열 → 데스크톱 다열)
- **톤앤매너**: 다크 테마 + 그린 그라디언트 포인트 컬러로 "AI시대 기술 연구소" 이미지를 표현
- **외부 의존성**: Tailwind CDN, Pretendard CDN — 별도 npm 빌드 환경 불필요

## 4. 검증

- 로컬 정적 서버(`python3 -m http.server`)로 `./output/index.html`을 구동
- Chrome 브라우저 자동화로 데스크톱 뷰포트에서 전체 섹션(Hero → 문제의식 → 철학 → 프로세스 →
  대상 → CTA → Footer)을 스크롤하며 레이아웃 깨짐 없이 렌더링되는 것을 확인
