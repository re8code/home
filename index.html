LANGUAGE

Agent Coding을 지시하려면 언어 자체에 대한 깊은 이해가 먼저입니다.

C/C++

메모리를 직접 다루며 컴퓨터가 동작하는 물리적 원리를 체득

Java

엄격한 타입 체계와 객체지향 설계로 대규모 시스템의 구조적 사고를 훈련

Python

쉬운 문법 덕분에 로직 자체에 집중하며, AI 시대 표준 언어로 확장되는 사고 훈련

JavaScript

브라우저에서 실행되는 유일한 언어로, 비동기 이벤트 흐름을 다루는 사고 훈련

Dart

선언형 UI 문법으로 하나의 코드가 여러 플랫폼에 반영되는 흐름을 설계

ALGORITHM

구조와 알고리즘으로 문제를 분해한다

정렬·탐색 알고리즘과 그 바탕이 되는 자료구조를 함께 훈련합니다.

정렬·탐색

버블 정렬

인접한 두 값을 비교·교환하며 O(n²)이 왜 느린지 체감하는 첫 정렬

선택 정렬

매 순회마다 최솟값을 찾아 앞으로 보내며 비교와 교환 비용을 구분

삽입 정렬

정렬된 자리에 값을 끼워 넣으며 데이터 상태에 따른 성능 차이를 확인

병합 정렬

절반씩 나눠 정렬한 뒤 합치는 분할 정복으로 안정적인 O(n log n)을 보장

퀵 정렬

기준값으로 좌우를 나누는 분할 정복 — 평균은 빠르지만 최악의 경우가 존재

이진 탐색

정렬된 배열의 중간값과 비교하며 탐색 범위를 절반씩 좁혀 O(log n)을 체감

너비 우선 탐색

큐로 가까운 노드부터 층층이 방문하며 최단 경로가 보장되는 이유를 확인

깊이 우선 탐색

스택으로 한 갈래를 끝까지 파고든 뒤 되돌아오며 같은 그래프의 다른 얼굴을 확인

자료구조

정렬·탐색이 어떤 구조 위에서 동작하는지, 스택부터 트리까지 직접 확인합니다.

스택

마지막에 넣은 값이 가장 먼저 나오는 LIFO — 함수 호출과 실행 취소(undo)의 원리를 체감

큐

먼저 넣은 값이 먼저 나오는 FIFO — BFS가 왜 큐를 쓰는지, 대기열 처리 원리를 체감

연결 리스트

노드가 다음 노드를 가리키며 이어지는 구조 — 배열과 다른 삽입·삭제 비용을 확인

해시 테이블

키를 해시 함수로 변환해 O(1)에 가깝게 저장·조회 — 충돌 처리 방식까지 확인

힙

부모가 항상 자식보다 크거나 작은 완전 이진트리 — 우선순위 큐와 힙 정렬의 기반 원리

이진 탐색 트리

왼쪽은 작게, 오른쪽은 크게 — 정렬 구조를 유지하며 탐색·삽입을 O(log n)에 수행

WEB & WEBAPP

구조를 실제 서비스로 흐르게 한다

프론트엔드부터 배포까지, 데이터가 실제로 흐르는 전체 파이프라인을 훈련

Frontend (React)

컴포넌트와 상태 흐름 중심의 UI 데이터 흐름 설계

Backend (Node / Spring)

API·DB 계층을 오가는 데이터 흐름의 구조적 설계

DevOps (Docker)

컨테이너와 서버 인프라로 서비스가 실제로 돌아가는 환경을 구성

CI/CD (GitHub Actions)

빌드·테스트·배포를 자동화해 안정적으로 릴리즈하는 흐름 설계

Full-stack 통합 프로젝트

기획부터 배포까지, 프론트·백엔드·인프라를 하나로 엮어 스스로 설계·구현

UNITY

인터랙티브한 데이터 흐름을 다룬다

실시간 렌더링·물리·상태 관리를 통해 데이터 흐름을 시각적으로 체화

U3D 입문

Unity 2D / 3D 기초

씬·컴포넌트 구조 중심의 게임 데이터 흐름 이해

UE 중급

Dev 심화
