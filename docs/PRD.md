# PRD.md — Recode Coding 홈페이지 리뉴얼

## 1. 배경
- `recode.ai.kr`은 현재 GitHub Pages로 배포된 정적 사이트. `index.html`(랜딩) + `src/graffiti*.html`(원장님의 낙서 게시판) + `src/lang-*.html`(언어별 코스 상세)로 구성되어 있다.
- 사이트 전체를 "대공사" 수준으로 리뉴얼하기로 결정함 (2026-08-20). 철학적 배경은 `NEED.md` 참고.
- `index.html` 리뉴얼은 애초에 별도 파일(`mockup.html`)에서 라이트 톤 시안으로 반복 검토를 거친 뒤, 최종 결정된 내용을 `index.html`에 옮기고 `mockup.html`은 삭제하는 방식으로 진행했다(2026-08-22 완료 — §8 참고).

## 2. 목표
- 1차 목표: `index.html`을 "첫 방문자를 위한 내비게이션 허브"로 재설계한다.
- "지식 전달이 아닌 훈련", "1:1 맞춤", "신입 시니어 양성"이라는 정체성을 방문 즉시 전달한다.
- 복잡한 설명 대신 큼직한 핵심 메시지와 동적 인터랙션(Swiper/AOS/GSAP)으로 "정적이지 않고 살아있는" 인상을 준다.

## 4. 타겟 사용자
- 주 타겟: 대학생 (프로그래밍 진로·훈련에 관심 있는)
- 부 타겟: 학부모, 원장(콘텐츠 관리자, 낙서장 운영)

## 5. 핵심 메시지 (`NEED.md` 기반)
- 핵심 지향점: "신입 시니어"를 1:1 훈련으로 길러내는 연구소.
- 3대 기둥: ① 훈련 중심·1:1 맞춤형 교육 ② Agent Coding 시대의 기술 철학 ③ 인간-AI 협업 구조(왼손-오른손).
- 카피 작성 시 3단 위계(핵심 문장 → 기둥 → 세부 논리)로 압축해서 표현한다.

## 6. 기능 요구사항
- 상단 내비게이션: 5갈래(Online Judge / 낙서장 / LMS / 프로젝트 의뢰 / 오프라인 문의) 진입점 제공.
- 히어로 섹션: 핵심 메시지 + 1:1 상담 CTA.
- 철학/차별화 섹션: 3대 기둥을 시각적으로 요약해 전달.
- 동적 요소: Swiper(캐러셀), AOS(스크롤 등장 애니메이션), GSAP(추가 인터랙션)을 적용해 스크롤 시 살아있는 느낌을 준다.
- 반응형: 기존 `mobile-menu.js` 기반 모바일 내비게이션 유지.
- 외부 링크(OJ/LMS/business/studio)는 새 탭으로 열리도록 처리. 4개 서브도메인 모두 별도로 직접 제작·개발 중이므로, 오픈 전까지는 "준비중" 처리 방식을 정해야 함(§8 참고).

## 7. 비기능 요구사항
- 빌드 도구 없는 정적 HTML + Tailwind CDN 구조를 유지한다(별도 결정 전까지).
- GitHub Pages 배포(`main` 브랜치, `/root`) 호환을 유지한다.
- 페이지별 Tailwind config 중복 정의 방식을 유지할지, 공통화할지는 `DEV_PLAN.md`에서 결정한다.

- OJ(`oj.recode.ai.kr`)는 2026-08-21부로 `index.html` 상단 내비게이션에서 실제 링크로 연결 완료(새 탭).
- Algorithm 코스 랜딩 구성(2026-08-22): `report/2026-08-22-algorithm-visualization-listup.md`에서 제안한 파일럿 우선순위(정렬→그래프탐색→이진탐색) 중 정렬을 먼저 다루기로 하고, `index.html` Algorithm 섹션(기존 4개 카드: 자료구조 기초/알고리즘 문제 해결/코딩테스트 대비/시스템 설계 기초 · Swiper 캐러셀)을 Language 섹션과 동일한 정적 그리드 5카드(버블/선택/삽입/병합/퀵 정렬)로 교체 완료. 처음엔 이 지시를 `lang-cp.html`류 12주형 커리큘럼 상세 페이지(`src/algo-sort.html`)로 오해해 제작했으나, 실제 의도는 랜딩 카드 구성이었음이 확인되어 정정 — `algo-sort.html`은 삭제하지 않고 남겨뒀지만 현재 미사용 상태.
  - **정렬 5종 시각화 상세 페이지 전부 완료(2026-08-22)**: `algo-bubble-sort.html`/`algo-selection-sort.html`/`algo-insertion-sort.html`/`algo-merge-sort.html`/`algo-quick-sort.html` — 전부 visualgo.net 스타일 막대그래프 시각화(재생/단계 이동/의사코드 하이라이트/배열 프리셋 4종)로 직접 조작하며 학습. `index.html` Algorithm 섹션 카드 5개 모두 `<a>`로 전환해 연결 완료 — Algorithm 코스가 Language처럼 카드 전부 실제 페이지를 가리키는 상태. 브레드크럼은 5개 파일 전부 `홈 / {알고리즘명}` 2단(Language 상세 페이지와 동일 패턴)으로 통일.
  - 정렬 진행 상태 표현이 알고리즘마다 다르게 구현됨: 버블(뒤에서 자라는 경계+조기종료)/선택·삽입(앞에서 자라는 경계, 선택은 조기종료 없음)/병합(재귀적 구간+최상위 병합에서만 완료)/퀵(조각난 확정 인덱스, pivot 편향으로 "정렬됨"·"역순" 둘 다 최악). 프리셋별 비교/교환(또는 기록) 횟수가 알고리즘 특성을 그대로 수치로 증명하도록 설계 — 클로드 인 크롬으로 5개 페이지 전부 프리셋별 통계 검증 완료.
  - **이진 탐색 시각화 페이지 완료(2026-08-23)**: `src/algo-binary-search.html` — 파일럿 2순위(그래프탐색→이진탐색 중 이진탐색부터 먼저 진행, 우선순위 순서와 다르게 착수). 정렬 페이지와 같은 막대그래프 엔진을 재사용하되, 배열은 항상 정렬 고정이고 대신 목표값 프리셋(중앙값 적중=최선 O(1)/일반/존재하지 않음=최악 O(log n)/첫 값=경계) 4종 + 직접 값 입력으로 탐색. 클로드 인 크롬으로 최선(비교 1회)·최악(비교 4회, not found) 모두 검증 완료.
  - **Algorithm 랜딩 카드 6번째로 연결 + 섹션을 Swiper 캐러셀로 전환(2026-08-23)**: 카드가 늘어나 정적 그리드로 한 화면에 다 담을 수 없어, "한 번에 5개 카드만 보이는" Swiper 캐러셀(다른 3개 섹션과 동일한 구조, 다만 `slidesPerView`를 화면 폭별 2/3/5로 고정)로 되돌렸다.
  - **그래프 탐색(BFS/DFS) 시각화 페이지 완료 + 랜딩 카드 7·8번째로 연결(2026-08-23)**: `src/algo-bfs.html`/`src/algo-dfs.html` — 동일한 9노드·12간선 그래프를 공유해 "같은 그래프, 다른 방문 순서"를 직접 비교하게 했다(BFS: A→B→C→D→E→F→G→H→I 레벨별 확산, DFS: A→B→E→I→G→C→F→D→H 한 갈래 깊이 우선). 클로드 인 크롬으로 두 순서 모두 검증 완료. "마지막 카드 하이라이트" 위치가 이진 탐색→DFS로 이동. **Algorithm 코스 파일럿 8종(정렬 5 + 탐색 3: 이진탐색/BFS/DFS) 전부 완료.**
  - **자료구조 6종 파일럿 착수(2026-08-23)**: 사용자와 논의 후 Stack/Queue/Linked List/Hash Table/Heap/BST 6종을 다음 파일럿 범위로 확정. 카드 14장(정렬·탐색 8 + 자료구조 6)을 한 캐러셀에 배지로 구분하는 대신, `index.html` Algorithm 섹션 안에 "정렬·탐색"/"자료구조" 두 서브그룹(각자 별도 Swiper·nav 화살표)으로 나누기로 결정 — 히어로 5개 카테고리 체계는 그대로 유지. 구조 분리와 자료구조 6개 카드(스택/큐/연결 리스트/해시 테이블/힙/이진 탐색 트리, 아이콘 포함)는 이번에 추가했으나, 상세 시각화 페이지는 아직 미제작 — 카드에 "준비중" 배지만 붙어 있고 링크는 없는 상태. 어떤 자료구조부터 만들지는 다음 지시에서 정함.
  - **스택 시각화 페이지 완료(2026-08-23)**: `src/algo-stack.html` — 자료구조 6종 중 첫 착수. push/pop 연산 시퀀스를 스크립트로 미리 작성해 재생하는 새 엔진, 동작 시나리오 4종(기본 Push/Pop·함수 호출 스택·괄호 검사·실행 취소) + 값 입력창과 Push/Pop 버튼으로 자유롭게 조작하는 커스텀 모드 제공. `#ds-swiper` 스택 카드를 "준비중" 배지에서 실제 링크로 전환. 나머지 5종(큐/연결 리스트/해시 테이블/힙/이진 탐색 트리)은 여전히 "준비중".
