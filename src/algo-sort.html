ALGORITHM

정렬 (Sorting)

정렬은 같은 문제를 해결하는 여러 방법의 시간복잡도를 비교하며 알고리즘적 사고를 처음 훈련하는 관문입니다. 버블 정렬부터 퀵 정렬까지 다섯 가지 알고리즘을 단계별로 다루며, 왜 어떤 방법은 느리고 어떤 방법은 빠른지 구조적으로 판단하는 눈을 기릅니다.

전체 5건

1. 버블 정렬 (Bubble Sort)

인접한 두 원소를 비교해 순서가 틀리면 교환하는 가장 직관적인 정렬 — O(n²)이 왜 느린지 체감하는 출발점

배열을 여러 번 훑으면서 인접한 두 값을 비교·교환하는 과정을 반복합니다. 코드는 가장 짧고 이해하기 쉽지만 최악·평균 시간복잡도가 O(n²)이라 실무에서는 거의 쓰이지 않습니다. 왜 느린 알고리즘인지 직접 손으로 추적하며, 이후 배울 효율적인 정렬과 비교할 기준점을 세웁니다.

2. 선택 정렬 (Selection Sort)

매 순회마다 남은 원소 중 최솟값을 찾아 앞으로 보내는 방식 — 교환 횟수가 적다는 특징을 이해

정렬되지 않은 구간에서 최솟값을 찾아 맨 앞과 교환하는 과정을 반복합니다. 비교 횟수는 버블 정렬과 같은 O(n²)이지만 교환 횟수는 최대 n번으로 훨씬 적다는 차이를 직접 비교하며, "비교 횟수"와 "교환 비용"을 구분해서 생각하는 관점을 익힙니다.

3. 삽입 정렬 (Insertion Sort)

이미 정렬된 부분에 새 원소를 알맞은 위치로 끼워 넣는 방식 — 거의 정렬된 데이터에서 왜 빠른지 이해

카드를 손에 들고 정렬하듯, 정렬된 구간에 새 원소를 뒤에서부터 비교하며 알맞은 자리로 옮깁니다. 평균·최악은 O(n²)이지만 이미 거의 정렬된 데이터에서는 O(n)에 가깝게 동작한다는 점을 실습으로 확인하며, 데이터 상태에 따라 알고리즘 성능이 달라진다는 감각을 기릅니다.

4. 병합 정렬 (Merge Sort)

배열을 절반씩 나눠 각각 정렬한 뒤 합치는 분할 정복 — 안정적인 O(n log n)을 보장하는 원리

배열을 더 이상 나눌 수 없을 때까지 반으로 쪼갠 뒤, 정렬된 두 부분을 하나로 합치는 과정을 재귀로 반복합니다. 항상 O(n log n)을 보장하고 안정 정렬(같은 값의 순서 유지)이라는 장점이 있는 대신, 병합 과정에 추가 배열 공간이 필요하다는 트레이드오프를 이해합니다. 분할 정복 패러다임을 정렬로 처음 체득하는 단계입니다.

5. 퀵 정렬 (Quick Sort)

기준값(pivot)을 정해 좌우로 나누는 분할 정복 — 평균은 빠르지만 최악의 경우가 존재하는 이유

pivot을 하나 정해 그보다 작은 값은 왼쪽, 큰 값은 오른쪽으로 분할(파티션)한 뒤 각 부분을 재귀적으로 정렬합니다. 평균 시간복잡도는 O(n log n)으로 실무에서 가장 많이 쓰이지만, pivot을 잘못 고르면 최악의 경우 O(n²)까지 나빠질 수 있다는 점을 직접 확인하며 pivot 선택 전략의 중요성을 이해합니다.
